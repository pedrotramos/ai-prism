### Added
- **UI design tokens** in `client/src/styles/tokens.css`, with a light and a dark value for each colour token. Colour now includes `--accent-strong`, `--accent-text`, `--danger`, `--success`, `--warning`, `--info`, disabled colours and `--focus-ring`. Also added: a 6-step type scale, an 8 px / 24 px / 32 px spacing rhythm, 4 radii, 3 shadows, one z-index scale and 3 motion durations. The Tailwind theme reads all of them (`text-faint`, `bg-accent-strong`, `rounded-card`, `z-modal`, `duration-fast`). See `docs/ui-tokens.md`.
- One global keyboard focus ring (`:focus-visible`, 2px `--focus-ring`, 2px offset).
- `prefers-reduced-motion: reduce` now stops animations and transitions, including the blinking stream cursor.

### Fixed
- **Text contrast reaches WCAG AA** on the welcome, chat, Settings and Deck Studio screens. axe `color-contrast` drops from 130 nodes to 0 across 16 runs (2 themes × 2 viewports). The fixes are new `--faint` values (dark `#858e9a`, light `#626b75`) and filled accent buttons on `--accent-strong`. Active tabs use `--accent-text`, and markdown links use a darker blue in light mode.
- Pinch zoom works on phones again: the viewport meta no longer sets `maximum-scale=1.0`.

### Removed
- The unused Tailwind `ink.*` palette and `lava.600`/`lava.700`. `lava` stays as a deprecated alias of `accent`.
