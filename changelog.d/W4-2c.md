### Changed

- **As rotas HTTP do servidor em TypeScript estrito.** Todos os módulos de `server/routes/` (admin, custos,
  decks, templates de deck, documentos, imagens, MCP, memória, mensagens, modelos, projetos, sessões,
  skills, planilhas, busca de ferramentas, busca na web, saúde e arquivos estáticos) passam de `.js` para
  `.ts` sem nenhuma mudança de comportamento: as mesmas rotas, a mesma cadeia de middlewares, os mesmos
  exports, assinaturas e retornos, agora com tipos que o `npm run typecheck` verifica. Os testes das rotas
  viraram `.test.ts` (as mesmas asserções). Cada `.js` em `server/routes/` ficou como um re-export de uma
  linha, porque o `server/index.js` (ainda em JavaScript) os importa por esse caminho.
