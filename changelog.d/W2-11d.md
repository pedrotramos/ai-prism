### Security

- **Admissão de credencial também no turno.** Toda tool MCP oferecida ao modelo agora vem de uma
  conexão que passa pela mesma regra do conectar (sem credencial compartilhada, sem credencial não
  verificada). Uma conexão salva antes da regra — ou uma referência gravada direto na sessão — a um
  MCP Service com credencial compartilhada não oferece nenhuma tool, em `/api/chat`, `/continue`
  e `/regenerate`. Isso inclui o MCP Service designado para a busca na web quando a tool nativa
  está desligada: ele só é usado pela própria `web_search`, nunca com a lista inteira de tools do
  servidor.
- O turno só lê o cache da admissão (nunca espera uma verificação): serviço do catálogo com classe
  confirmada passa direto; um serviço conectado por nome ainda não verificado fica de fora naquele
  turno e é verificado em segundo plano, valendo a partir do turno seguinte. A classe em cache vale
  10 minutos no turno.
