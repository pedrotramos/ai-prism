### Added

- **Dashboard de operação no bundle**: `databricks.yml` declara `dashboards.ai_prism_ops`
  (`dashboards/ai-ops.lvdash.json`, "AI Prism — Operations") ao lado do de custos, no mesmo
  warehouse. Um `bundle deploy` entrega os dois; o de operação fica como rascunho até alguém
  publicá-lo. As consultas dos dois foram executadas num workspace de teste.
- **Smoke pós-deploy nos scripts de deploy**: `deploy.sh` e `deploy.ps1` rodam `npm run smoke`
  contra a URL do app (com o token OAuth do perfil, nunca impresso) depois do auto-config e saem
  com código != 0 se ele falhar. Pular: `--skip-smoke` / `-SkipSmoke` / `AI_PRISM_SKIP_SMOKE=1`.
- `tests/deployWrappers.test.mjs` (os dois scripts, com CLI e npm falsos) e
  `tests/bundleDashboards.test.mjs` (todo dashboard declarado; widgets só leem datasets que existem).

### Changed

- **Os scripts de deploy compilam antes de deployar**: `deploy.sh` e `deploy.ps1` rodam
  `npm run bundle` antes do `bundle deploy` e param se o build falhar, já que os PRs de feature
  não commitam mais `client/dist`/`server-dist`. Pular: `--skip-build` / `-SkipBuild` /
  `AI_PRISM_SKIP_BUILD=1`. Sem `npm` no PATH, o script para no início e indica as duas opções.
- As mensagens de `deploy.sh`/`deploy.ps1` agora saem em inglês (os nomes de parâmetro não mudaram).
- `dashboards/README.md` em inglês, com traduções em `docs/pt-BR/dashboards/` e `docs/es/dashboards/`.

### Deploy notes

- O notebook instalador (`Instalar AI Prism.py`) roda o `deploy.sh` num cluster sem Node: ele
  precisa exportar `AI_PRISM_SKIP_BUILD=1` e `AI_PRISM_SKIP_SMOKE=1` (ver
  `docs/onboarding-deployment.md`).
