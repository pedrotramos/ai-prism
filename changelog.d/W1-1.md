### Changed

- **AppKit vira o boot padrão**: `node server-dist/index.cjs` agora é um launcher fino
  (`server/boot.cjs`) que sobe o app pelo Databricks AppKit (`server-dist/appkit.mjs`): `/health`
  responde `{"status":"ok"}` em JSON, e todas as rotas do Express continuam iguais, montadas dentro do
  `server()` do AppKit. `npm run build:server` (e `npm run bundle`) gera os três arquivos
  (`index.cjs`, `legacy.cjs` e o lado AppKit dividido em `appkit.mjs` + chunks `appkit-*.mjs`, porque o
  Databricks Apps recusa o deploy se qualquer arquivo passar de 10 MB); o script `build:server:appkit`
  deixa de existir.
- **Sem plugin `lakebase()` no AppKit**: o `server/db.js` continua dono do pool do Postgres, então o
  boot não pede `PGPORT`/`PGSSLMODE`/`LAKEBASE_ENDPOINT`. A telemetria interna do AppKit segue
  desligada (`disableInternalTelemetry: true`). Decisões no
  [ADR 0001](docs/adr/0001-appkit.md), agora em inglês e com status Accepted.
- **CI com G-boot**: depois do `npm run bundle`, o passo "Boot (G-boot)" roda
  `tests/appkit-boot.test.mjs` contra o `server-dist/` gerado e um workspace simulado (SCIM `/Me`):
  AppKit por padrão, legado com `APPKIT_BOOT=0`, body JSON de 2 MB sem 413, **todo arquivo de
  `server-dist/` ≤ 9,5 MB** (folga sob o limite de 10 MB por arquivo) e `app.yaml` sem `APPKIT_BOOT: '1'`.

### Deploy notes

- **Rollback do boot por variável**: o `app.yaml` **não** define `APPKIT_BOOT` (sem a variável, o
  launcher sobe o AppKit) e documenta o rollback em comentário. Se o AppKit der problema, descomente as
  linhas `APPKIT_BOOT: '0'` e faça o redeploy do **mesmo** build (sem rebuild): o launcher sobe o
  listener Express legado (`server-dist/legacy.cjs`). Nunca use `'1'`: é o sinal interno de "não
  escutar", e o `server-dist/index.cjs` antigo (antes do PR de release) subiria sem escutar a porta.
- **`server-dist/` com mais arquivos**: passa de um arquivo de ~8,6 MB para ~21,2 MB em 30 arquivos
  (nenhum acima de 9,5 MB) enquanto os dois caminhos convivem; os nomes dos chunks `appkit-*.mjs` mudam
  a cada build. Ele só é regerado e commitado no PR de release.
