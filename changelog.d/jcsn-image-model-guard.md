### Security

- **O servidor valida o modelo de imagem contra o catálogo habilitado.** Um modelo de imagem que o admin desabilitou não pode mais ser chamado: o turno (chat, continuar e regenerar) resolve o modelo entre os habilitados (escolha do cliente, seleção salva, padrão da organização, primeiro habilitado) e, sem nenhum, não oferece a tool `generate_image`; a tool não cai mais num padrão desabilitado, e `PUT /api/image-models/selected` responde 400 para um id fora do conjunto habilitado. Nova chave `IMAGE_GENERATION=off` desliga a geração de imagem (sem a tool e com `GET /api/image-models` vazio). Desabilitar todos os modelos de imagem desliga a geração (sem fallback para o padrão curado; a aba Modelos avisa), e uma falha ao ler o catálogo não oferece a tool naquele turno. Ideia de jcsn13.
