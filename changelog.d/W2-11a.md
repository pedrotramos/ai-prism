### Added

- **Busca na web nativa, MCP primeiro (`web_search` + `web_fetch`).** As duas tools voltam a ser
  oferecidas ao modelo quando há um backend de busca disponível para o usuário do turno. A busca
  percorre uma cadeia ordenada (`WEB_SEARCH_BACKEND`, padrão `auto`): o MCP gerenciado
  `system.ai.web_search` onde o workspace o tem, depois o MCP Service externo indicado em
  `WEB_SEARCH_MCP_SERVICE` (Firecrawl, You.com, Tavily, Exa… registrado no Unity Gateway, com a
  chave do provedor na connection do UC) e, por último, Brave, Tavily ou um SearXNG próprio com
  chave em secret do Apps (`bundle/optional/web-search-secret.yml.example`). Os dois caminhos MCP
  usam o token do próprio usuário. A disponibilidade é verificada por usuário em segundo plano e
  nunca atrasa o turno; sem nada configurado num workspace sem o MCP gerenciado, nada muda.
  A diretiva de fontes de apresentações e documentos só cita `web_search` quando a tool está no
  turno. Guia em `docs/web-search.md` (inglês, pt-BR e espanhol); decisão em
  `docs/adr/0007-web-search-backend.md`.
- **Custo da busca no taxímetro.** Cada busca respondida grava uma linha `web_search` no ledger,
  com o provedor que respondeu (Brave USD 5 e Tavily USD 8 por 1.000 buscas; MCP sem preço até o
  admin definir `tool:web_search[:<provedor>]` ou `WEB_SEARCH_PRICE_PER_1K_USD`). Turno cancelado
  não grava. `docs/adr/0008-fixed-cost-ledger-rows.md`.
- **Status da busca para o admin.** `GET /api/admin/web-search/status` (cadeia, estado por
  backend, presença de chave, últimas 24 h) e `POST /api/admin/web-search/verify` (uma busca real
  por backend, só contagens, no máximo 1 a cada 10 s). Nunca mostram chave nem consulta.

### Changed

- `callMcpTool` aceita `{ timeoutMs, throwOnError, signal }`; sem opções, o comportamento é o de
  antes para todos os chamadores.
- O alias legado `WEB_SEARCH_CONNECTION` só vale como nome de três partes de MCP Service; o
  caminho antigo que caía na primeira tool do servidor foi removido.

### Security

- O resultado de toda busca vem num envelope fixo de conteúdo externo não confiável, com os
  marcadores neutralizados dentro do texto do provedor. Logs de busca não trazem consulta,
  resultado nem erro do provedor. O MCP Service designado para a busca continua recusado em toda
  conexão de usuário (credencial compartilhada); com a tool nativa ativa, conexões do usuário a
  esse serviço ou a `system.ai.web_search` são ignoradas no turno. Detalhes em
  `docs/security-threat-model.md` (G12, G14).

### Deploy notes

- Para usar um provedor MCP externo: registrar o servidor no Unity Gateway, restringir o serviço
  à tool de busca, dar `EXECUTE` (+ `USE CATALOG`/`USE SCHEMA`) aos usuários e definir
  `WEB_SEARCH_MCP_SERVICE` no `app.yaml`. Para desligar: `WEB_SEARCH_DISABLED=1` ou a política
  `web-search` na aba Tools.
