### Changed

- **UI string catalogs split per domain**: `client/src/lib/locales/{pt,en,es}.js` became
  `locales/<lang>/{common,composer,message,sidebar,welcome,settings,admin,studios,errors}.js`,
  merged per language by `locales/index.js`. Independent UI areas can now change copy
  without editing the same 1,100-line file, which removes a merge-conflict hot spot.
  No string changed: `locales/catalogs.test.js` checks every key against per-domain
  snapshots of the previous catalogs, identical key sets across pt/en/es, and that each
  key namespace lives in one domain file. Regenerate snapshots after an intentional copy
  change with `UPDATE_LOCALE_SNAPSHOTS=1 node --test client/src/lib/locales/catalogs.test.js`.
