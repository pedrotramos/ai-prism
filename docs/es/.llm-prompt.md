# Style guide for es translations (human or machine-assisted)

Use this together with the general rules in [docs/README.md](../README.md#translations)
and the [glossary](../glossary.md). A machine-assisted draft is stamped `status=machine`,
shows the review banner, and becomes `current` only after a native speaker reviews it.

You are translating AI Prism documentation from English into neutral Latin-American
Spanish.

- Audience: the person who deploys and operates AI Prism in their company's own
  Databricks workspace, a contributor, or a security reviewer. Never write "para un
  cliente": the reader is the company that runs the app.
- Use "tú" forms and the imperative without "usted" ("ejecuta", "abre", "revisa");
  avoid voseo and Spain-only forms ("vosotros", "ordenador", "fichero").
- Short sentences, active voice, no marketing tone. Keep the English paragraph order;
  do not add or drop sections, tables or code blocks.
- Screen labels: quote the es label from the glossary or from
  `client/src/lib/locales/es/*.ts`, in italics, exactly as the UI shows it
  (*Configuración → Design system*).
- Never translate: product and platform names (AI Prism, Databricks, Lakebase,
  AI Gateway, Unity Catalog, Genie One, Genie Agents, Vector Search, MCP, Skills,
  Design system, workspace, bundle, service principal), commands, file names, env
  vars, API paths, JSON/YAML keys and anything inside a code block except comments.
  "workspace" stays in English, as in the UI.
- Common technical terms: despliegue (deploy), reversión or rollback, token,
  endpoint, log, dashboard, prueba de humo (smoke test), pull request, commit.
- Keep links working: link to the es page when it exists (`docs/es/...`), else to the
  English page; fix `#anchors` to the target's own headings.
- Line 1 is the marker; line 2 the H1; then the language switcher
  `[English](...) · [Português (Brasil)](...) · **Español**`; for `status=machine`,
  the banner follows:
  `> Esta traducción fue hecha con ayuda de IA y espera revisión nativa. En caso de duda, la [versión en inglés](...) es la referencia.`
