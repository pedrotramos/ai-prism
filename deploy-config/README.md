# deploy-config

Generated by `deploy.sh` / `deploy.ps1` when you pass a models file (`--models-file` / `-ModelsFile`):
the validated copy is staged here as `models.json` (git-ignored) and synced with the app, which reads it
(`server/modelsConfig.ts`). The deploy removes it again when you deploy without a models file. Nothing
else lives here. See `models.example.json` and `docs/onboarding-deployment.md`.
